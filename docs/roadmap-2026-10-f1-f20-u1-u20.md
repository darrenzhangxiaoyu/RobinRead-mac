# 2026-10 大迭代路线图：F1–F20 功能轮 + U1–U20 视觉轮

> 本文件是 2026-10-07 启动的「20 大功能 + 20 大 UI/动效/配色升级」马拉松的执行底稿。
> 每轮 = 独立开发 agent 实现 + 独立审查 agent 全量验证（探针全绿才过关）。
> 版本基线：v2.12.68。每 2–4 轮合一个版本号递增（由主线决定）。

## 原则

1. 与既有 53 轮迭代（R1–R53）零重复——先查 README/CHANGELOG 再动手。
2. 每轮必须配离线探针（scripts/diag-*.js），并注册进 scripts/run-all.js 的 OFFLINE 列表。
3. 本地优先：不引入需要外部服务器的功能；AI 功能走既有 LLMService 且无 Key 可降级。
4. 性能不退步：主线程不引入同步 IO；列表/阅读路径不引入整表重拉。
5. IPC 遵守信封约定（handle() 自动包 {ok,data}）；frameless 窗口禁 window.prompt/alert/confirm（用 ui-prompt.js）。
6. I18N：所有新文案进 I18NStrings.js（中英双语），跑 node 校验。
7. 主题：新样式一律走 OKLCH 令牌，禁硬编码色值（phase12 radius 护拦会拦 6px 类硬编码）。
