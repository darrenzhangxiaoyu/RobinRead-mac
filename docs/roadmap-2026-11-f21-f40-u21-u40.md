## 原则（沿用一轮 + 二轮增补）

1. 与一轮 F1-F20 / U1-U20 及 R1-R53 零重复——先查 README/CHANGELOG 再动手。
2. 每轮配离线探针（scripts/diag-*.js）注册进 run-all.js；目标门禁 94 → 110+。
3. 本地优先：不引入外部服务器依赖；AI 功能走 LLMService 且无 Key 可降级。
4. 性能不退步：主线程无同步 IO；列表/阅读路径无整表重拉。
5. IPC 信封约定 / frameless 禁 prompt/alert/confirm / I18N 静态键 / OKLCH 令牌——全部沿用。
6. **环境红线**：开发 agent 禁 npm install / npx electron@版本（node_modules 脆弱，拆空用 scripts/restore-from-lock.js）；跑探针只用 `npx electron scripts/diag-*.js`；含转义改动只走 Write/Edit。
7. 迁移链从 v22 起步（只进 DatabaseMigrations.js）。
